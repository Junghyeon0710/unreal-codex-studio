# ue-cpp

Inspect module and target rules, nearby conventions and engine version. Respect UHT headers/macros, GC references, world lifetime, threading, component registration and replication. Use a declared API instead of public mutable state when callers need invariants. Generate the exact build plan with tools/studio.py build --target <actual target>. Distinguish static review from a successful engine build and runtime test.

Follow the workspace AGENTS.md and current user authorization. Use tools actually available in this session. Report observed results and material limits.
