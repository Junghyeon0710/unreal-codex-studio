# ue-data

Identify the authoritative source (CSV, JSON, workbook or asset), row structure and import route. Preserve row keys and foreign references. Use official MCP schemas for asset edits/reimport, then read back representative rows and verify gameplay consumers. Do not independently edit generated CSV and workbook sources in conflicting ways. Report schema changes and migration needs.

Follow the workspace AGENTS.md and current user authorization. Use tools actually available in this session. Report observed results and material limits.
