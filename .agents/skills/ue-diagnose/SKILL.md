# ue-diagnose

Capture the exact command/tool call, engine version, project, first relevant error and reproduction. Classify transport/schema/project-binding, UHT/compiler/linker, Blueprint, startup, runtime or asset-load failure. Read the owning source and bounded relevant log sections. Reproduce in an isolated fixture when possible. Fix the root cause and rerun the failed check; keep unrelated map/asset corruption outside scope.

Follow the workspace AGENTS.md and current user authorization. Use tools actually available in this session. Report observed results and material limits.
