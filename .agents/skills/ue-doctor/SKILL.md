# ue-doctor

Run python tools/studio.py doctor with --project, --engine and --url. Distinguish missing plugin, disabled plugin, unreachable endpoint, incompatible schema and wrong project. Inspect output and engine log; do not equate local plugin files with an active connection. Read docs/official-mcp.md for the 5.8.4 blank serverInfo behavior. Stop mutations until project binding succeeds.

Follow the workspace AGENTS.md and current user authorization. Use tools actually available in this session. Report observed results and material limits.
