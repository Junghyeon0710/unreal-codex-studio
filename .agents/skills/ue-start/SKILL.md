# ue-start

Read AGENTS.md and docs/getting-started.md. Resolve the explicit .uproject and engine root, then run scan and doctor. Record paths in gitignored studio.local.json only when the user requested configuration. Identify feature scope and choose the smallest relevant roles. For new demos, use the example command with an empty destination. Do not modify an existing game just to demonstrate setup.

Follow the workspace AGENTS.md and current user authorization. Use tools actually available in this session. Report observed results and material limits.
