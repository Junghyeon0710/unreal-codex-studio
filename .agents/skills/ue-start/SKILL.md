# ue-start

Read AGENTS.md and docs/getting-started.md. Resolve the explicit .uproject and engine root, run scan when useful and doctor before actual editor operations. Record paths in gitignored studio.local.json only when the user requested configuration. Identify scope and let the Astra manager select the smallest sufficient roster and meaningful checks using docs/feature-loop.md; no fixed role count. Respect configured model overrides or omission/inheritance; do not force shipped Astra/Sol IDs. Narrow explanation/read-only work may need no delegation or journal. For new demos, use the example command with an empty destination. Do not modify an existing game just to demonstrate setup.

Follow the workspace AGENTS.md and current user authorization. Use tools actually available in this session. Report observed results and material limits.
