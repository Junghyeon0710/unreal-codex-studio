# ue-test

Choose an existing named test suite or implement a relevant behavior test. Use tools/studio.py test --test-filter <filter> to inspect then execute the command, or discover official AutomationTestToolset schemas. Verify discovered/executed counts, failures and completion from the exported report. A process returning zero with zero tests is not a pass. Keep headless test scope distinct from visual/playable behavior.

Follow the workspace AGENTS.md and current user authorization. Use tools actually available in this session. Report observed results and material limits.
