# ue-ui

Identify the project's UI stack and input flow. Discover UMG and Object toolsets, list actual widget/slot properties before setting them. Verify bindings, visibility, focus navigation, viewport scale and intended device inputs. Capture the changed screen using available official tools and inspect it. Do not call a screenshot a controller test or add CommonUI to unrelated projects automatically.

Follow the workspace AGENTS.md and current user authorization. Use tools actually available in this session. Report observed results and material limits.
